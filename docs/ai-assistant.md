# مساعد دعبول عبر Groq

راجع [إصلاح الفهم والسرعة بتاريخ 28 أكتوبر](understanding-speed-update.md) للتشخيص الجديد وتمييز أسئلة الدفعة عن الحفظ. يتطلب الإصدار الجديد ترحيل `0011` قبل النشر، ويُظهر إشعار انتظار واحداً عند ازدحام الخدمة دون ادعاء حفظ التبليغ.

المساعد الجديد اختياري. من دون مفتاح API يبقى المسار القديم للجدول والمساهمات شغالاً. عند ربط Groq، يستطيع أي طالب إرسال تبليغ طبيعي بالخاص أو بمنشن البوت بالكروب؛ لا يحتاج التبليغ الجديد موافقة المالك.

**وصول المنشن من الكروب يحتاج إعداد Telegram أيضاً:** إذا كان البوت عضواً عادياً وGroup Privacy مفعّلاً، لا يوصّل Telegram المنشن النصي العادي إلى البوت. من حساب مالك البوت افتح BotFather، أرسل `/setprivacy`، اختر `@daaboolbot` ثم `Disable`، وأزل البوت من كروب النقاش وأعد إضافته لتطبيق التغيير. يصبح قادراً على استقبال رسائل الكروب؛ الكود يجيب فقط على الرسائل الموجّهة إليه والردود المرتبطة به. أدمن القناة ليس أدمن كروب النقاش المرتبط بها. راجع [Privacy Mode الرسمي](https://core.telegram.org/bots/features#privacy-mode).

في Inline يظهر الجواب داخل نتيجة قابلة للاختيار؛ اختيارها يشارك الجواب في المحادثة. للرد التلقائي من حساب البوت أرسل رسالة منشن عادية في الكروب بعد ضبط الخصوصية.

## ما يتغير

- محادثة عامة باللهجة العراقية، وردود على المنشن والرد على البوت، ونتائج Inline قابلة للمشاركة.
- الردود الاجتماعية تراعي الشكر والمجاملة والمزاح والسياق القريب، ولا تفتح سؤال مساعدة جديداً بعد كل مجاملة. بعد إرسال ملف الأسماء يُحفظ ملخص نجاح الإرسال للمحادثة نفسها فقط. سياق الدفعة معروف، وتضاف الأسماء المطابقة للسؤال عند الحاجة دون تحميل PDF كاملاً في كل طلب أو ربط اسم بحساب من التخمين. المحادثة تستخدم تنويعاً في الصياغة؛ استخراج المواعيد والتبليغات يحتفظ بإعداد الدقة الثابت.
- الرسالة الواحدة قد تنتج عدة تبليغات: امتحان، كوز، واجب، مناقشة، ملاحظة أو تغيير محاضرة ليوم محدد.
- يُحفظ النص الأصلي والمصدر مع تبليغات منسوبة للطلبة. الاحتمال يبقى احتمالاً، والموعد أو المجموعة غير المذكورين يبقيان غير محددين. أرقام محاضرات المادة المشمولة منفصلة عن توقيت المحاضرة.
- يستطيع الطالب تعديل تبليغه أو إلغاءه أو التراجع عن آخر تغيير. المالك يستطيع الإدارة؛ تصحيح طالب لتبليغ آخر يبقى منسوباً له ولا يمحو كلام صاحب التبليغ.
- «شعدنا هذا الأسبوع؟» يعرض المواعيد المتبقية من اليوم حتى السبت. للسجل الكامل قل «هذا الأسبوع حتى اللي صارت»، أو اطلب تاريخاً محدداً؛ الأسبوع الماضي والجاي يحافظان على حدودهما الكاملة.
- لإلغاء تبليغ معروض، رد على رسالته بـ«هذا التبليغ قديم احذفه». يُحدّد السجل من مرجع محفوظ ونسخته، مع التحقق من صاحبه أو المالك؛ لا يحتاج إعادة كتابة المادة والموعد. إذا كانت الرسالة تضم عدة تبليغات أو تغيّرت النسخة، يطلب تحديد المقصود. الرسائل القديمة التي سبقت حفظ المراجع تحتاج إعادة عرض التبليغ مرةً واحدة.
- Inline للقراءة والمشاركة فقط؛ لا يحفظ تبليغاً ولا يستعمل ذاكرة الخاص. ذاكرة المحادثة معزولة حسب الطالب والمحادثة والموضوع، وتستخدم آخر ثلاث جولات خلال يوم؛ تُنظف بعد سبعة أيام.
- التذكيرات الدينية تعتمد مكتبة أولية من **٦٩ مقتطفاً موثّقاً من الصحيحين**، بفائدة وتطبيق منفصلين عن النص. يمنع تكرار الحديث ٣٠ يوماً والمعنى المتقارب ١٤ يوماً. المكتبة قابلة للتوسيع؛ ليست ١٢٠ مادة بعد.
- الخبر اليومي من RSS لـMIT News وScienceDaily وNew Atlas: عنوان وملخص عربي ورابط المصدر ومعاينة صورته إن أتاحها المصدر وتليگرام. لا تُولّد الأخبار أو الأحاديث من ذاكرة النموذج. هذه قائمة مصادر محددة، وليست بحثاً شاملاً في الويب. [تفاصيل المصادر والمواعيد الحالية](natural-daily-update.md).

## إدخال المفتاح

للربط والتشغيل تلقائياً، شغّل:

```sh
npm run setup:ai:browser
```

افتح العنوان المحلي الذي يظهر، ثم الصق المفتاح بالخانة المخفية واضغط **«ربط وتشغيل دعبول»**. تُفحص صلاحية المفتاح بطلب صغير إلى Groq، ثم تُشغّل الاختبارات ويُبنى المشروع وتُطبّق migrations وتُرفع الأسرار ويُنشر البوت ويُفحص. تُفعّل التذكيرات الدينية من الموعد القادم إذا كان كروب النشر مربوطاً. تبقى الصفحة محلية على جهازك ولا ترسل رسائل تجريبية للطلاب. ويمكن تنفيذ الخطوات نفسها بإدخال مخفي في الطرفية عبر `npm run activate:ai`.

للحفظ المحلي فقط دون تفعيل، استخدم الطريقة التالية.

أنشئ مفتاحاً من [Groq Console](https://console.groq.com/keys)، ثم شغّل داخل مجلد المشروع:

```sh
npm run setup:ai
```

الإدخال مخفي. يُحفظ المفتاح فقط في `.local/assistant-secrets.json` بصلاحية `0600`، وهو مجلد مستثنى من Git. لا ترسل المفتاح بالكروب أو المحادثة ولا تضعه كوسيط أمر. هذا الأمر يحفظ محلياً ولا ينشر أو يرسل طلبات AI.

```sh
npm run setup:ai -- --check
```

يفحص وجود المفتاح محلياً فقط، من دون طباعته أو اختباره لدى المزوّد.

## التفعيل على Worker

طبّق المخطط قبل رفع المفتاح ونشر الإصدار:

```sh
npx wrangler d1 migrations apply daabool-contributions --remote
npm run check
npm run setup:ai -- --upload
npm run deploy
```

الرفع يمرر المفتاح إلى Wrangler عبر stdin، ولا يطبعه. لا يعدّل صلاحيات Telegram أو يسجّل حساب Groq نيابة عنك. للتجربة المحلية، ضع المفتاح في `.dev.vars` وطبّق migrations محلياً؛ الاختبارات تستخدم بيانات ومفاتيح وهمية.

المتغيرات:

| المتغير | الاستخدام |
|---|---|
| `GROQ_API_KEY` | سرّ حساب Groq؛ النموذج الافتراضي `openai/gpt-oss-120b` |
| `GROQ_ENABLED=false` | تعطيل المساعد والعودة للمسار القديم |
| `GROQ_MODEL` | اختيار نموذج متاح لحسابك عند الحاجة |
| `GROQ_API_KEYS` | مصفوفة JSON سرّية لمفاتيح مخوّلة؛ جميعها تشترك في سقف Groq نفسه ولا تضاعف الحصة |
| `GEMINI_API_KEY` | احتياط اختياري عند تعطل Groq أو نفاد حصته |
| `GEMINI_MODEL` | افتراضياً `gemini-3.6-flash` |

الحصص مشتركة بين مثيلات Worker ومحفوظة في D1، مع مهلة انتظار بعد `429`. لا يفعل البرنامج ترقية حساب أو وسيلة دفع؛ استخدم حسابات مجانية. حدود المزوّد الفعلية تبقى المرجع، والسقوف المحلية لا تحول حساباً مدفوعاً إلى مجاني.

عند ازدحام حصة الدقيقة أو فشل اتصال مؤقت، تبقى رسالة الخاص أو المنشن قيد المعالجة ويعيد Telegram تسليمها تلقائياً؛ لا تُسجّل رسالة فشل نهائية ولا يُحتسب الطلب على الطالب مرتين. يبقى تاريخ الرسالة الأصلية مرجعاً لـ«باچر» وأيام الأسبوع بعد التأخير. يحتاج ذلك تحديث قاعدة البيانات `0009` قبل نشر الكود. نفاد الحصة اليومية أو مفتاح غير صالح أو نتيجة غير قابلة للتحقق يبقى فشلاً نهائياً؛ Inline والتذكيرات يحتفظان بردود الاحتياط السريعة.

## إدارة التذكيرات

يعرض الأدمن **«دعبول التذكيرات الدينية»** لإعداد نشرات القناة. أوامر «شغّل التذكيرات» و«وقّف التذكيرات» تتحكم بالتذكيرات الشخصية فقط.

مواعيد القناة بتوقيت بغداد: الطقس 06:30 من الأحد إلى الخميس و09:00 الجمعة والسبت؛ آية اليوم 12:30 بأيام الدوام و10:30 الجمعة والسبت؛ جدول باچر 16:00 إذا كان دواماً؛ خبران كحد أقصى 17:00 و21:00؛ والذكر 18:00. الصلوات الخمس تُرسل حسب مواقيت الرمادي الفعلية، بما فيها الفجر، من دون فترة هدوء؛ يوم الجمعة لا يذكر البوت موعد خطبة أو إقامة غير موثّق.

ملخص التبليغات التلقائي الساعة 18:00 ونشرات الحركات الأسبوعية متوقفة. الجدول يعتمد نسخة الجدول الأكاديمي، ويُظهر المواد والمجموعات من دون أوقات المحاضرات. الخبر والذكر والآية تحتاج مصدراً حديثاً وموثقاً؛ إذا تعذر التحقق، يتخطى البوت النشرة بدلاً من اختلاق محتوى.

## تجربة قبول فعلية بعد الربط

1. ابدأ بكروب اختبار يختاره المالك. أرسل من حساب طالب رسالة فيها مناقشة بلا موعد، وكوز محدد اليوم، واحتمال كوز؛ تحقق من فصلها ونقل المطلوب والاحتمال بدقة.
2. اسأل «شعدنا باچر؟» بالخاص والمنشن وInline، وتأكد من شمول التبليغات الجديدة وأن Inline لا يحفظ شيئاً.
3. عدّل تبليغك ثم جرّب التراجع. تأكد من رفض زر قديم ومنع طالب آخر من مسح تبليغك.
4. جرّب تذكيراً بمعاينة المالك ثم في موعده بالكروب الاختباري؛ تحقق من المصدر ومنع التكرار.

الاختبارات الآلية تتحقق من الحفظ والجدولة والعزل وإعادة المحاولة باستخدام مخرجات AI وهمية. جودة فهم Groq الفعلية وسرعة حسابك وحصته تحتاج تجربة بمفتاح حقيقي قبل الاعتماد الكامل.
